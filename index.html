Get Started in 3 Steps

Works on Windows, Linux, and macOS.

1

Install Claude Code

npm install -g @anthropic-ai/claude-code
2

Clone & Configure

# Clone the repository
git clone https://github.com/inyogeshwar/claude-code-free.git
cd claude-code-free

# Copy a provider settings file
cp settings/settings-openrouter.json ~/.claude/settings.json

# Edit and add your API key
nano ~/.claude/settings.json
3

Launch Claude Code

claude

Quick Switch Script

Use the interactive script to switch providers instantly:

# Windows
.\scripts\switch.ps1

# Linux / macOS
chmod +x scripts/switch.sh
./scripts/switch.sh
