Troubleshooting

Common issues and their fixes.

"Invalid API key"

Verify your key is active on the provider's dashboard. Make sure it starts with the correct prefix (e.g., sk- for AgentRouter, sk-or- for OpenRouter).

"Connection refused"

Check your internet connection. The provider may be temporarily down — visit their status page. Ensure the base URL matches your provider exactly.

"Model not found"

Not all providers support all models. Try the default model for your provider. Check the provider's documentation for supported model names.

Settings not taking effect

Make sure you saved the file. Restart your terminal completely. On Windows, setx requires a new terminal window to take effect.
